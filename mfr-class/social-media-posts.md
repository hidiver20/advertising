**Posting tips**

- **Facebook:** paste as written. Links are clickable.
- **Instagram:** links in captions don't click. Swap each link line for "📲 Link in bio to book!" and put the class page (or the single-class booking link) in your bio.
- **Class page link:** Post 7 points people to the class calendar. Replace `[CLASS PAGE LINK]` with the page address once it's live (see [README.md](README.md#putting-the-page-online)).
- **Suggested rhythm:** two posts a week, landing on Sundays and Mondays so the reminder is fresh before Tuesday class.
